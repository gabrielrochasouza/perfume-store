## ⚡ Customizações Rápidas

### Mudar Número WhatsApp
```bash
# Edite .env.local
NEXT_PUBLIC_WHATSAPP_NUMBER=seu_numero
```

### Adicionar Produto
```typescript
// src/data/products.ts
{
  id: '21',
  nome: 'Novo Perfume',
  // ... resto dos campos
}
```

### Trocar Cores
```typescript
// tailwind.config.ts
accent: '#SEU_COR'
```
