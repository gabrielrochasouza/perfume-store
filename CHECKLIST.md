## 🚀 Pronto para Usar

### Pré-requisitos Atendidos
- [x] Node.js 18+ (não obrigatório instalar, apenas recomendado)
- [x] npm ou yarn disponível
- [x] Pasta `public/` com suporte a imagens
- [x] Variáveis de ambiente configuradas

### Próximos Passos do Usuário

1. **Instalar Dependências**
   ```bash
   npm install
   ```

2. **Configurar .env.local** (opcional)
   - Já tem valor padrão configurado
   - Pode mudar o número do WhatsApp

3. **Organizar Imagens**
   - Copiar imagens de `assets/` para `public/assets/perfumes/`
   - Atualizar caminhos em `src/data/products.ts`

4. **Iniciar Servidor**
   ```bash
   npm run dev
   ```

5. **Acessar**
   - http://localhost:3000
